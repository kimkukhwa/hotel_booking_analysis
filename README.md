# Hotel Booking Analysis

## What
A hotel-booking analysis practice project exploring a price-based urgency messaging feature.

## Why
This project showcases statistical analysis, Python functions, data storytelling, and turning findings into practical recommendations.

## Outcome
The analysis organizes the insights to help persuade a product owner to investigate the opportunity and proposes experiments to test the feature's impact.

## Data
Raw data is not included. The notebook's saved outputs are provided so readers can review the analysis without running it.
